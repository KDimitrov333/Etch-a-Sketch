# Etch-a-Sketch Project

## Description
This is a simple interactive Etch-a-Sketch web application built using HTML, CSS, and JavaScript from scratch. Users can draw by hovering over grid squares, and dynamically resize the grid to customize the drawing area.

## Features
- Hover over squares to "draw" by changing their color.
- Resize the grid dynamically (supports sizes from 1x1 to 100x100).
- Responsive design for improved usability across different screen sizes.

## Technologies Used
- **HTML**: Structuring the application layout.
- **CSS**: Styling the grid and user interface.
- **JavaScript**: Implementing dynamic grid creation and user interaction.

## How to Use
1. Open the project in a web browser at https://kdimitrov333.github.io/Etch-a-Sketch/.
2. Hover over the grid squares to draw.
3. Click the "Resize the Grid" button to change the grid dimensions (enter a number between 1 and 100 when prompted).
